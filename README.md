# 海上賽船

因數與倍數的**雙人對戰**遊戲，為教室的電子大屏（1920×1080 橫式）設計。對應翰林版五年級上學期數學**第二單元「倍數與因數」**。

兩個學生各站螢幕一邊，各看各的題目。答對一題，自己的船就往前一格，先到終點的贏。

這是[海底拔河](https://shinechiang07-cell.github.io/sea-tug/)的姊妹作：角色、題目、作答板完全一樣，只有比法不同。

## 跟拔河差在哪

| | 海底拔河 | 海上賽船 |
|---|---|---|
| 比法 | 你進我退，互相拉扯 | 各跑各的，比誰先到 |
| 對手答對 | 會把你的進度拉回去 | 不影響你 |
| 適合 | 程度相近、喜歡對抗 | 程度有落差、怕挫折的組合 |

賽船裡**自己答對的每一格都不會被拿走**，落後的人看得到自己一直在前進。

## 怎麼玩

1. **兩隊各選一個角色**上船：章魚、螃蟹、鯊魚、鯨魚、水母、海龜。船和作答板的顏色跟著角色走，兩隊不能選同一個。
2. **選時間**：1～5 分鐘。賽道長度跟著時間變，**每分鐘 8 格**（2 分鐘就是 16 格）。
3. **選難度**：簡單／普通／困難，全場統一。
4. 用數字鍵打出答案，按「送出」。
   - **答對**：船往前一格。
   - **答錯**：船不會動，直接換下一題。不公布答案，也不罰時間。
5. **先到終點的贏**。
6. 時間到還沒有人到終點，就看**誰的船在前面**。
7. 時間到剛好**平手**就進延長賽：下一題先答對的贏。

## 題目

跟海底拔河共用同一套出題器：九種題型、三種難度，兩隊的題目各自出、互不相同，答案一律是整數。題型細節見[海底拔河的說明](https://github.com/shinechiang07-cell/sea-tug#題目)。

> 這個單元是第一次教因數和倍數，還沒有教到「公因數」「公倍數」「質數」，題目文字不使用這些名詞。

## 賽道長度為什麼是「每分鐘 8 格」

一題大約要 7、8 秒。照這個速度，答得穩的學生會在時間快到的時候衝線；答得快的會提早到；兩邊都慢，就由時間到的時候誰在前面決定。兩種結束方式都會發生，不會每一場都拖到時間到，也不會一下子就結束。

## 兩艘船公平嗎

遠的那艘船畫得比較小（有遠近感），但**船的位置是用船頭算的**，兩艘船的船頭只看進度、跟船畫多大無關。遠的那艘不會因為畫得小就比較晚碰到終點線。

## 音樂

跟海底拔河同一首：奧芬巴哈《天國與地獄》的康康舞曲主題（1858 年，公有領域），用瀏覽器的 Web Audio 現場合成，沒有任何音檔。最後 20 秒會加速。

## 技術

單一 `index.html`，沒有建置流程、沒有相依套件、沒有音檔和圖檔。角色、船和場景全用 SVG 畫的。字型從 Google Fonts 載入（粉圓 Huninn ＋ Fredoka）。

主控台輸入 `__selftest(60000)` 會產生 6 萬題並用另一套算法重算答案，上線前跑過的結果全部為 0。
